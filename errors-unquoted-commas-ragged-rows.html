A row has more fields than the file has columns

⚠️ Row 14 has 22 fields but the file has 21 columns — an unquoted comma is splitting a text field in two.

CSV files use commas to separate columns — so any comma inside your text (a title like "Mug, Large", a description, a tag list) must be protected by wrapping the whole field in double quotes. Miss one, and every value in that row shifts one column to the right: prices land in the inventory column, SKUs land in the weight column, and the import fails or imports garbage.

Fix it by hand

  1. Open the file in a spreadsheet and find the row whose values look shifted.
  2. Wrap any field containing a comma in double quotes: "cotton, summer".
  3. Escape a quote inside a quoted field by doubling it: "the \"big\" mug".
  4. Re-export as CSV (UTF-8) rather than editing the raw text if you can.

This is the single most destructive CSV mistake because it corrupts columns silently — a checker that counts fields per row catches it instantly.
