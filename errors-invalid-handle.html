Invalid handle in your Shopify product CSV

⚠️ The handle "Blue T-Shirt!" contains characters Shopify does not allow.

The Handle column is how Shopify identifies each product. Every row with the same handle belongs to the same product, so the handle has to follow strict rules:

  • Lowercase letters, numbers and hyphens only
  • No spaces, no capitals, no symbols like !, & or '

When a handle breaks the rules, Shopify may reject the rows, create a duplicate product with a mangled URL, or — worst of all — attach your variants to the wrong product.

Fix it by hand

  1. Take the handle and lowercase it: Blue T-Shirt! → blue t-shirt!
  2. Replace every run of spaces or symbols with a single hyphen: → blue-t-shirt
  3. Trim hyphens from the start and end.
  4. Apply the exact same new handle to every row of that product, or its variants will split into separate products.
