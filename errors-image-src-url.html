Image Src must be a public URL

⚠️ Image Src contains "example.com/mug.jpg" — the https:// scheme is missing.

Shopify does not upload images from your computer during a CSV import — it downloads them from the address in Image Src. That address must be a complete, publicly reachable URL:

  • Starts with http:// or https:// — example.com/mug.jpg fails; https://example.com/mug.jpg works
  • No spaces anywhere in the URL
  • Not a local path (C:\images\mug.jpg) and not behind a login
  • Points directly at an image file (jpg, png, gif, webp)

Fix it by hand

  1. Upload the images somewhere public first (your existing store's Files section works).
  2. Copy each file's full URL into Image Src.
  3. Number Image Position 1, 2, 3… per product — gaps or repeats make Shopify drop or reorder images.
