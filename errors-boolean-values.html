Only TRUE or FALSE belong in Shopify’s yes/no columns

⚠️ Published contains "yes" — Shopify reads anything that is not TRUE as false.

Several Shopify CSV columns are switches: Published, Variant Taxable, Variant Requires Shipping and Gift Card. They accept exactly two values: TRUE or FALSE.

The danger is silent: values like yes, 1, True or Y may import without an error — and be read as FALSE. That is how products end up unpublished, untaxed, or marked as not needing shipping without anyone noticing.

Fix it by hand

  1. Convert yes / 1 / True / TRUE (with stray spaces) to TRUE.
  2. Convert no / 0 / False to FALSE.
  3. After importing, spot-check one product's visibility and tax settings in the admin.
